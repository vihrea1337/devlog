# История изменений

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/): сверху новое.
Версии Android-приложения — `versionName` в `androidApp/app/build.gradle.kts`.

## 2026-10-10 — переезд и качество отчётов (Android 1.1.0)

### Изменено
- **Отчёт пишется по темам, а не по дням.** Раньше ИИ получал черновик «по дням, списком шагов»
  (решения и проблемы туда не попадали вовсе) с задачей «перепиши, сохрани все даты» — и возвращал
  тот же список. Теперь ИИ получает полную структуру записей и пишет разделы «Кратко», «Главные
  результаты», «Ключевые решения», «Сложные проблемы», «Что дальше»; «Цифры периода» и
  «Хронологию» (одна строка на день) считает код.
- Отдельная модель для отчётов `GROQ_REPORT_MODEL` (по умолчанию `openai/gpt-oss-120b`) с откатом
  на основную; бюджет токенов подобран под лимит бесплатного Groq (8000 токенов/мин).
- Промпт разбора записи: решения в форме «что выбрал — почему», проблемы «что сломалось →
  причина → решение», меры предосторожности — не проблемы, без канцелярита.
- Переезд на новый сервер (`/opt/devlog`, общий с другими проектами, свой порт 34444).

### Исправлено
- Ответ 429 от Groq больше не делает запись `failed`: она ждёт без траты попытки, воркер
  выдерживает паузу по `retry-after` (раньше при импорте пачкой падала треть записей).
- Строгий JSON-режим Groq иногда отвергал ответ модели (400 `json_validate_failed`) — теперь
  повтор без строгого режима.
- **Утечка:** записи проектов с выключенным ИИ уходили в Groq при сборке отчёта.
- Одновременные регистрации одного email давали 500 вместо 409.
- Markdown: `код` в отчётах, нумерованные списки; `snake_case` больше не становится курсивом.
- Android: офлайн-очередь сама уезжает на сервер при появлении сети; экран входа показывает
  настоящую причину ошибки (короткий пароль, занятый email, нет связи).

### Добавлено
- Страница о сервисе и установки `/install.html`, «Конфиденциальность» и «Условия использования»;
  `/demo` — пример отчёта; APK раздаётся с сервера (`/download/DevLog.apk`).
- CI: смоук-тест настоящего Docker-образа на Postgres — все миграции Flyway применены, сквозной
  сценарий API (регистрация → запись → отчёт → публичная ссылка). Release по тегу (APK +
  дистрибутив), Deploy по кнопке через SSH.
- `SECURITY.md`, `CHANGELOG.md`, `LICENSE`.

## 2026-09-02 … 09-04 — офлайн и импорт

- Офлайн-кэш и очередь операций в Android (SQLDelight, last-write-wins), курсор синхронизации
  `sync_seq` вместо `updated_at`.
- Импорт текстовых логов, приватные репозитории GitHub (токен шифруется AES-GCM), починка импорта
  GitHub (Compare API вместо исчезнувшего `payload.commits`), импорт GitLab, экспорт отчёта в GitHub.
- Живая проверка на телефоне по всему чек-листу.

## 2026-08-12 … 08-14 — фундамент

- Миграции Flyway; в прод едет дистрибутив, а не fat-jar (fat-jar терял миграции).
- Очередь ИИ в базе с повторами вместо «выстрелил и забыл»; отказ старта с дефолтным JWT-секретом.
- Поиск и теги, календарь активности, тёмная тема, живые обновления (SSE), синхронизация,
  импорт коммитов GitHub, общий модуль `shared/`, отчёты в Android.

## 2026-07-20 … 07-22 — MVP

- JWT-аккаунты, записи, ИИ-структуризация (Groq), отчёты с публичной ссылкой, проекты с
  выключателем ИИ, деплой (Docker + Caddy + DuckDNS), CI, первое Android-приложение.
