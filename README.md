# DevLog — рабочий дневник разработчика

[![CI](https://github.com/vihrea1337/devlog/actions/workflows/ci.yml/badge.svg)](https://github.com/vihrea1337/devlog/actions/workflows/ci.yml)

Сервис-«летопись»: превращает сырые заметки о проделанной за день работе в структурированный
отчёт с датами, шагами, решениями и итогами. Такой отчёт можно раз в месяц отдать работодателю —
чтобы история разработки не сводилась к одним коммитам на GitHub.

**Боевой инстанс:** `https://vihreaschedule.duckdns.org:34444/`

## Как это работает

1. **Заметка** — пишешь свободным текстом, что сделал за день.
2. **ИИ структурирует** её в фоне: суть, шаги, принятые решения, проблемы, итог, теги
   (строгий JSON, статусы `в очереди → обрабатывается → готово`).
3. **Отчёт за период** собирается из записей (Markdown), причёсывается ИИ и публикуется
   по ссылке — её можно отправить работодателю без регистрации.

## Возможности

- 🔐 **Аккаунты и изоляция** — регистрация/вход по JWT, bcrypt-хеш пароля; каждый видит только своё.
- 📝 **Записи** — CRUD, лента по дням, переобработка.
- 🤖 **ИИ-структуризация** записей (Groq), в фоне, с суточным лимитом на пользователя.
- 📊 **Отчёты** за период — Markdown + ИИ-редактура + публичная ссылка `/r/{token}`, скачивание `.md`.
- 🗂 **Проекты** — группировка записей, фильтр ленты; **выключатель ИИ по проекту** для
  конфиденциальной работы (такие записи не отправляются на обработку).
- 🌐 **Веб-интерфейс** — одностраничное приложение, которое отдаёт сам бэкенд.

## Стек

| Слой | Технологии |
|------|-----------|
| Бэкенд | Kotlin, Ktor 3, Exposed, HikariCP |
| База | PostgreSQL 16 |
| Авторизация | JWT, bcrypt |
| ИИ | Groq (OpenAI-совместимый API) |
| Веб | HTML/CSS/JS без фреймворков (отдаётся бэкендом) |
| Android | Kotlin, Jetpack Compose, Retrofit, kotlinx.serialization |
| Деплой | Docker Compose, Caddy (HTTPS через DuckDNS), Let's Encrypt |
| CI | GitHub Actions (тесты на H2 + сборка fat-jar) |

Архитектура — клиент-серверная, сервер = единственный источник правды. Заложено на вырост:
мобильные клиенты планируются на Kotlin Multiplatform + Compose Multiplatform из общего кода.

## Запуск локально

Нужны JDK 21 и Docker.

```bash
# 1. Поднять базу
docker compose -f backend/docker-compose.yml up -d      # Postgres на порту 5433

# 2. (по желанию) ключ Groq для ИИ — иначе записи просто останутся «в очереди»
#    backend/secrets.properties:  groq.api.key=ВАШ_КЛЮЧ

# 3. Запустить сервер
cd backend && ./gradlew run                              # http://localhost:8080
```

## Тесты

```bash
cd backend && ./gradlew test        # 27 интеграционных тестов на встроенной H2 (без Docker)
```
