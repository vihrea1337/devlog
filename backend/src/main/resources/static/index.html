Проекты

Группируйте записи по клиентам или продуктам. Для конфиденциального проекта выключите ИИ — его записи не отправляются на обработку.

Импорт коммитов с GitHub

Коммиты за день превращаются в одну запись — дальше её разбирает ИИ, как обычную заметку. Без токена видна только публичная активность за последние ~90 дней.

Импорт коммитов с GitLab

Та же идея, что у GitHub. У GitLab нет публичного доступа, поэтому токен обязателен (scope read_api), а логин не нужен — импорт видит активность владельца токена.

Импорт текста

Вставьте любой текст с датами вида ГГГГ-ММ-ДД в строках — лог сессии, экспорт чата, свои заметки. Каждый день станет отдельной записью. Повторная вставка дублей не создаст.

Отчёт за период

ИИ пишет текст по темам: результаты, решения, проблемы. Цифры и хронологию считает код. Перед отправкой отчёт можно поправить.
