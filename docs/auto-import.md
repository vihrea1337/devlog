# Автоимпорт файлов дня

Как сделать, чтобы файлы дня (`ГГГГ-ММ-ДД.md` с разделами «Сделано», «Проверено», «Нехватки»,
«Не делалось», «Цифры») сами попадали в DevLog, без ручной загрузки в вебе.

Сервер к папке на вашем ПК доступа не имеет — поэтому отправляет ПК: скрипт
`tools/push-day-files.mjs` (Node 18+, без зависимостей). Сервер сам разбирается, что новое,
что дописано, а что не изменилось: повторная отправка ничего не дублирует, а запись,
которую вы правили в DevLog руками, скрипт не затрёт.

> **Перед тем как включать:** если файлы дня — о работе на работодателя, убедитесь, что
> отправлять их в DevLog можно. Разделы разбирает код, но отчёт с ИИ (Groq) отправит текст
> во внешний сервис — для такого проекта выключите ИИ (Проекты → «ИИ выкл.»).

## 1. Токен для скрипта

Веб DevLog → «Файлы дня» → «Токен для скриптов» → назовите («Домашний ПК») → «Выпустить».
Токен показывается **один раз** — скопируйте. Он умеет только импорт (файлы дня и текст):
читать, удалять, делиться отчётами им нельзя. Потерялся или больше не нужен — «Отозвать».

Положите токен в переменную окружения пользователя Windows (не в файлы и не в репозиторий):

```powershell
[Environment]::SetEnvironmentVariable("DEVLOG_IMPORT_TOKEN", "dli_…", "User")
```

Id проекта, в который класть записи, — из адреса или ответа `GET /api/projects`
(в вебе проект выбирается фильтром ленты).

## 2. Проверка руками

```powershell
node tools\push-day-files.mjs --dir "C:\путь\к\записям" --project <id> --dry-run   # что уйдёт
node tools\push-day-files.mjs --dir "C:\путь\к\записям" --project <id>             # отправить
```

По умолчанию берутся файлы за последние 45 дней (`--days`), из папки и подпапок
(например, `2026-10\`). Коды возврата: 0 — отправлено, 1 — сервер/сеть не ответили,
2 — неверные аргументы.

## 3а. Раз в вечер — Планировщик заданий Windows

```powershell
$action  = New-ScheduledTaskAction -Execute "node" -Argument 'C:\Users\<вы>\Desktop\Projects\devlog\tools\push-day-files.mjs --dir "C:\путь\к\записям" --project <id> --days 7'
$trigger = New-ScheduledTaskTrigger -Daily -At 23:30
Register-ScheduledTask -TaskName "DevLog — файлы дня" -Action $action -Trigger $trigger
```

## 3б. Сразу после записи — хук Claude Code

Если файлы дня пишет Claude Code, хук `PostToolUse` отправит файл сразу после записи.
В режиме `--hook` скрипт читает JSON о записанном файле со входа и отправляет **только его**
и только если файл лежит в `--dir` и в имени есть дата — остальные правки пропускает молча.

В `.claude/settings.json` той папки, где пишутся записи (или в пользовательских настройках):

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "node C:/Users/<вы>/Desktop/Projects/devlog/tools/push-day-files.mjs --hook --dir \"C:/путь/к/записям\" --project <id>"
          }
        ]
      }
    ]
  }
}
```

Токен хук берёт из той же переменной `DEVLOG_IMPORT_TOKEN`.
