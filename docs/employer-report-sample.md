# Образец: «Отчёт работодателю» за месяц

Так выглядит отчёт, который DevLog собирает из файлов дня (`ГГГГ-ММ-ДД.md`) и коммитов —
по кнопке («Отчёты» → вид «Работодателю») или сам, по расписанию («Автоматика»). Данные ниже
выдуманы: проект «Погодное приложение», исполнитель «Анна».

Откуда что берётся:

| Часть | Кто пишет | Из чего |
|---|---|---|
| Заголовок, период, строка «Исполнитель · Проект · Составлен» | код | профиль, проект, даты |
| Кратко, Сделано, Проверено, Передано другим, Не сделано | ИИ (без ИИ — код, пункты как в записях) | разделы файлов дня, коммиты дней без файла |
| По неделям | ИИ — «Кратко» каждой недели | недельные тексты (готовые отчёты или собранные на ходу) |
| Цифры периода | код | «Цифры» файлов дня: за день — сумма, «к концу дня» — было → стало; коммиты — по GitHub |
| Хронология | код | строка на день |

Отчёт за день — те же разделы без «По неделям» и «Хронологии»; за неделю — без «По неделям».
Перед отправкой отчёт читается и правится («Править»), затем — ссылка или PDF.

# Погодное приложение: отчёт за октябрь 2026

_Период: 1 октября 2026 — 31 октября 2026_

**Исполнитель:** Анна · **Проект:** Погодное приложение · **Составлен:** 31 октября 2026

## Кратко
В октябре довела Android-клиент до сборки для тестеров: экран прогноза, виджет, уведомления
о погоде и настройки. Главный результат — две сборки ушли тестерам, замечания первой закрыты.

## Сделано
- **Экран прогноза** — почасовой и недельный прогноз, переключение городов, загрузка без
  «прыжков» страницы.
- **Виджет на главный экран** — два размера, обновление раз в час, тёмная тема.
- **Уведомления** — утренняя сводка и предупреждения о грозе; включаются в настройках
  отдельно для каждого устройства.
- **Настройки** — единицы измерения, язык (русский, английский), выход из аккаунта.
- **Замечания тестеров к первой сборке** — 9 из 11 исправлены (календарь, перевод, кнопка «Назад»).

## Проверено
- Автотесты на каждый экран: перед каждой сборкой все зелёные.
- Сборки для тестеров 3 и 17 октября со списком проверки.
- На эмуляторе и телефоне: уведомления при закрытом и открытом приложении, тёмная тема.
- Тесты нашли и помогли исправить ошибку в списке городов при быстрой прокрутке.

## Передано другим и нехватки
- Почасовой прогноз для гор — нужен новый метод API, передано бэкенд-разработчику Олегу (№12).
- Иконки погоды для ночи — ждут макета от дизайнера.

## Не сделано и почему
- Замечания тестеров №4 и №7 — ждут решения руководителя (меняют вид экрана).
- Перевод на тайский — после согласования текстов.
