## Фаза 1 — MVP, веб, с аккаунтами
Сердцевина продукта. Сценарий целиком в браузере.
- [x] Таблицы БД на Exposed (`Tables.kt`) + подключение (`Database.kt`) + `docker-compose.yml` — компилируется, фэт-джар собирается. _Живая проверка (создание таблиц в БД) — после `docker compose up` (Docker был выключен)._
- [x] JWT-авторизация: регистрация, вход, `GET /api/me` (bcrypt-хеш пароля, JWT-токен). Покрыто интеграционными тестами на H2 (4 теста) — зелёные.
- [ ] CRUD записей (`/api/entries`) + фоновая обработка ИИ (Claude API, строгий JSON)
- [ ] Генерация отчёта за период (`/api/reports`) + экспорт в Markdown
- [ ] Веб-страница от бэкенда: вход → ввод заметки → лента по дням → кнопка «отчёт за месяц»
- [ ] Лимиты ИИ на пользователя
- **Готово, когда:** можно зарегистрироваться, добавить заметку, получить структуру
  и скачать отчёт за месяц — в браузере.
